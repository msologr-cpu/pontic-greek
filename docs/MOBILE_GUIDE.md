# iOS & Android Installation & Usage Guide — Pontic Greek Keyboard (Keyman v6.1)

Official Pontic Greek mobile keyboard published through **SIL Keyman** (`keyman.com/keyboards/pontic_greek`) with the embedded **Pontic Sans v6.0** font, so all Pontic diacritics (`ζ̌ χ̌ σ̌ ς̌ κ̌ ξ̌ ψ̌ γ̆ α̤ ο̤ ά̤ ό̤`) render accurately without third-party font hacks.

## Installation

### Recommended: Install Directly from SIL Keyman Catalog
1. Install the free **Keyman** app:
   - **Android:** Google Play Store -> *Keyman*
   - **iOS / iPadOS:** App Store -> *Keyman*
2. Inside Keyman -> **Settings -> Add Keyboard** (or visit <https://keyman.com/keyboards/pontic_greek> in your mobile browser) and search for **Pontic Greek**.
3. Install the keyboard and enable **Keyman** in your device's system keyboard settings (alongside Gboard / Apple system keyboards — tap the globe `🌐` / keyboard switcher key to toggle languages).

### Side-Loading Local Package (`pontic_greek.kmp` v6.1)
1. Download [`pontic_greek.kmp`](../pontic_greek.kmp) onto your phone.
2. Open it with the **Keyman** app (or in Keyman -> Settings -> Install Keyboard -> Install from file).

## How to Type on Mobile (v6.1)

### 1. Direct Long-Press (Fastest Method)
Press and **hold** any base key and slide onto the Pontic popup variant:

| Hold Key | Popup Options |
|---|---|
| `σ` | `σ̌`, `ς`, `ς̌` *(also long-press `ς` for `ς̌`)* |
| `ζ` | `ζ̌` |
| `χ` | `χ̌` |
| `κ` | `κ̌` |
| `ξ` | `ξ̌` |
| `ψ` | `ψ̌` |
| `γ` | `γ̆` |
| `α` | `ά`, `α̤`, `ά̤` |
| `ο` | `ό`, `ο̤`, `ό̤` |
| `ε`, `η`, `ι`, `υ`, `ω` | `έ`, `ή`, `ί ϊ ΐ`, `ύ ϋ ΰ`, `ώ` |

### 2. Two-Step Diacritic Composition (Pre-Fix or Post-Fix)
- **Post-fix:** Type any vowel or consonant first, then tap `΄` (top-right) for tonos or long-press `΄` → `ˇ` to apply caron / breve / diaeresis below automatically.
- **Pre-fix:** Tap `΄` and/or long-press `΄` → `ˇ` first, then type the target letter (works in either order).

### 3. Auto-Shift & Caps Lock (New in v6.1)
- **Single Capital Letter:** Tap **Shift** (`⇧`) once, tap a capital letter (or long-press an uppercase variant / compose a pre-fix dead key while shifted), and the keyboard **automatically returns to the lowercase layer** without needing a second Shift tap.
- **Caps Lock:** **Double-tap Shift** to engage the sticky Caps Lock layer (`caps`) on both phones and tablets; tap Shift again to return to lowercase.

### 4. Bottom-Row Punctuation
Dedicated `,`, `'`, `.` keys are immediately visible on the bottom row in both lowercase and uppercase layers:
- Hold `,` → `; : ( ) - /`
- Hold `'` → `’ " « »`
- Hold `.` → `? ! …`
