# План: клавиатура «в системе», без костылей

Цель — уйти от установки скриптов вручную к тому, чтобы понтийская раскладка
ставилась штатными средствами каждой платформы (в идеале — уже была в системе).
Ниже пути от самого быстрого к самому стратегическому.

## 6.1. Keyman official repository (быстрее всего, все платформы сразу)

Подать наш пакет в открытый репозиторий `keymanapp/keyboards` на GitHub.
После ревью клавиатура попадает в официальный каталог Keyman и ставится в один
клик на **Android, iOS, Windows, macOS, Linux и в браузере**. Один сабмишн
закрывает все платформы; пользователи находят её по запросу «Pontic Greek».

Что нужно: чистые метаданные, лицензия MIT (есть), документация, welcome-стр.
Заготовки у нас уже лежат в `keyman/source/`.

**Статус:** 
- PR подан в официальный репозиторий: [keymanapp/keyboards#4113](https://github.com/keymanapp/keyboards/pull/4113)
- Пакет собран в `release/p/pontic_greek/` с поддержкой мобильных, десктопных (`any`) и веб-платформ, визуальной клавиатурой (`.kvks`), встроенным шрифтом Pontic Sans с GPOS-якорями и полным набором документации.
- Пройдена локальная компиляция и верификация тулчейном `kmc --for-publishing` без предупреждений и ошибок.
- Ожидается: прохождение проверок CI и ревью ментейнеров Keyman.

## 6.2. macOS — нативно

Есть `pnt-macos-v3.keylayout`. macOS поддерживает мёртвые клавиши с выводом
строк (буква + гачек) без сторонних программ. Оформить `.bundle` + иконка,
установщик `.pkg`, публикация через GitHub Releases и Homebrew cask.

## 6.3. Windows — нативно

Ограничение платформы: штатные мёртвые клавиши Windows выдают только ОДИН
символ, пары «буква+гачек» через dead key не сделать. Варианты:
- раскладка через MSKLC, где отдельная клавиша даёт сам комбинируемый гачек
  ПОСЛЕ буквы (порядок набора: буква → гачек) — работает везде без запуска
  программ;
- AHK оставить как «умный» вариант (наш порядок: гачек → буква) в подписанном
  установщике MSI с автозапуском.
Сделать оба: нативная раскладка как база, AHK — как удобство.

## 6.4. Linux

Заявка в `xkeyboard-config` (freedesktop): попадание туда = раскладка едет в
комплекте каждого дистрибутива.

## 6.5. Стратегический уровень — CLDR и Noto

- **Unicode CLDR** (keyboard data): оттуда данные берут Microsoft, Apple,
  Google. Долгий путь, но это и есть «в системе из коробки». У понтийского есть
  ISO 639-3 `pnt` — формальное основание имеется.
- **Апстрим-фикс в Noto:** отправить наши недостающие якоря (в т.ч. χ, Σ Ξ Ψ)
  в проект Google Noto. Если примут — гачек начнёт правильно сидеть в системных
  шрифтах Android сам, и проблема «гачек стоит не там на телефоне» исчезнет
  в корне, а не будет обходиться каждый раз отдельным шрифтом.

## Порядок

1. Стабилизировать текущую версию (сделано, актуальная — 5.1).
2. Сабмит в Keyman repository (6.1) — максимальный охват минимальными силами.
3. Параллельно PR якорей в Noto (6.5, вторая часть) — устраняет корень проблемы
   отображения на телефонах.
4. Нативные раскладки macOS/Windows (6.2, 6.3) как отдельные релизы.
5. Linux и CLDR (6.4, 6.5) — долгий трек.
