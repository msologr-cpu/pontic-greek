# Скачать шрифты и раскладки Pontic v6.0

Прямые ссылки: файл скачивается сразу, вход в GitHub не нужен.
Шрифты те же, что на pontos.world/pontoskey/test.html (калибровка Д.И. Зимова).

## Всё одним архивом

- [Pontic_v6.zip](https://raw.githubusercontent.com/msologr-cpu/pontic-greek/main/downloads/Pontic_v6.zip) — 8 шрифтов, раскладка Keyman (.kmp) и раскладка для Mac (.keylayout).

Установка: двойной щелчок по файлу, затем «Установить».

## Раскладки

- [Keyman: Windows, Android, iPhone](https://raw.githubusercontent.com/msologr-cpu/pontic-greek/main/keyman/build/pontic_greek.kmp) — сначала установите бесплатную программу Keyman (keyman.com), потом откройте этот файл в ней. Двойным щелчком без Keyman он не открывается.
- [Mac](https://raw.githubusercontent.com/msologr-cpu/pontic-greek/main/pnt-macos-v3.keylayout) — скопировать в папку «Библиотеки/Keyboard Layouts» и выбрать в настройках клавиатуры.

Шрифт внутри .kmp собран 28.08.2026, без последней калибровки, поэтому шрифты из списка выше нужно установить отдельно.
