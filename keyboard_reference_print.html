Как набирать понтийские символы

Мёртвая клавиша — не печатает сама, а ждёт следующего нажатия. Сначала нажмите мёртвую клавишу, потом букву.

ˇ
Гачек — клавиша ' (апостроф) Работает в обычном слое и с Shift
  • '+Z(ζ)→ζ̌зета
  • '+X(χ)→χ̌хи
  • '+S(σ)→σ̌сигма
  • '+K(κ)→κ̌каппа
  • '+J(ξ)→ξ̌кси
  • '+C(ψ)→ψ̌пси
  • '+Shift+Z→Ζ̌ Χ̌ Σ̌ Κ̌ Ξ̌ Ψ̌заглавные
  • '+Пробел→ˇсам символ
̤
Две точки снизу — клавиша / «Секретная» понтийская клавиша
  • /+A(α)→α̤альфа с точками
  • /+O(ο)→ο̤омикрон с точками
  • /+Shift+A→Α̤заглавная
  • /+Shift+O→Ο̤заглавная
  • /+Пробел→̤сам символ
˘
Бреве — клавиши Shift + , Только для γ / Γ
  • Shift+,+G(γ)→γ̆гамма с бреве
  • Shift+,+Shift+G→Γ̆заглавная
  • Shift+,+Пробел→˘сам символ
΄
Тонос — клавиша ; (стандартный греч.) Как в обычной греческой раскладке
  • ;+A(α)→άальфа
  • ;+E(ε)→έ   H(η)→ή
  • ;+I(ι)→ί   O(ο)→ό
  • ;+Y(υ)→ύ   V(ω)→ώ
  • ;+Пробел→΄сам символ
