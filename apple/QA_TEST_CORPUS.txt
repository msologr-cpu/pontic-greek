-------------------------------------------------------

4. iOS / Mobile Touch Keyboard Sequences (Auto-Shift & Caps Lock)
-----------------------------------------------------------------
- Single-tap Shift -> tap Π -> o -> ν -> τ -> ο -> ς
  Expected output: "Πόντος" (after adding tonos on ο); layer automatically returns to lowercase after Π.
- Single-tap Shift -> long-press Ζ -> Ζ̌ -> tap α -> ν
  Expected output: "Ζ̌αν"; layer returns to lowercase after Ζ̌.
- Single-tap Shift -> tap ΄ (dead key stays shifted) -> tap Α
  Expected output: "Ά"; layer returns to lowercase after Α.
- Single-tap Shift -> long-press ΄ -> ˇ (stays shifted) -> tap ΄ (stays shifted) -> tap Α
  Expected output: "Ά̤"; layer returns to lowercase after Α.
- Double-tap Shift (Caps Lock) -> Α, Β, Γ, Space, comma, Ζ̌ -> tap Shift to unlock -> α
  Expected output: "ΑΒΓ ,Ζ̌α"; stays in Caps Lock until manually unlocked.
- Long-press σ -> verify popup contains [σ̌, ς, ς̌].
